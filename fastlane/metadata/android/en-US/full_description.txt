<p><i>WebMonkey</i> is a no-frills light-weight web browser with support for Greasemonkey user scripts. It uses the <a target='_blank' rel='nofollow' href='https://github.com/wbayer/webview-gm'>WebView GM library</a> to enhance the native Android System WebView with support for Greasemonkey functions and the management of user scripts.</p><p><br><b>Caveats:</b></p><ul><li>userscripts only run in the top window</li><li>they are not loaded into iframes</li></ul><p>Note that „no-frills“ can also be interpreted as „bare-bones“. If you’re looking for a polished GUI with bells and whistles, this is not for you…</p>
